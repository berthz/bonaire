# Snel op je telefoon

De makkelijkste gratis route is GitHub Pages:

1. Maak op GitHub een nieuwe repository, bijvoorbeeld `bonaire-dive-buddy`.
2. Upload alle bestanden uit deze map.
3. Zet GitHub Pages aan voor de `main` branch / root.
4. Open de gegenereerde `https://...github.io/.../` URL in Chrome op je Android.
5. Kies Chrome-menu → **Toevoegen aan startscherm** / **App installeren**.
6. Open de app één keer online zodat de PWA-shell en alle duikdata gecachet worden.

De duikdata en app-interface zijn offline beschikbaar. Google Maps zelf is een externe dienst en vereist normaal gesproken internet; download daarom ook het gebied Bonaire in de Google Maps-app voor offline autorouting.
